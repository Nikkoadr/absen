## antislop
Instalasi antislop di proyek ini bersifat global (bukan per-proyek), mencakup semua skill yang tersedia.
For UI, copy, people, mobile layout, or code comments work, read the core `antislop` rules and then the skill for the task:
- UI / visual: `antislop-ui`
- Copy & text: `antislop-copywriting`
- People: `antislop-human`
- Mobile / responsive: `antislop-layoutmobile`
- Code comments: `antislop-code`
Before starting, resolve the usage mode in strict order: explicit session instruction first, then the global preference (`npx antislop-ai --mode`), then ask. A session instruction always wins. For a resolved mode, announce `antislop active: <mode> (session override).` or `antislop active: <mode> (global preference).` once before presenting findings or making edits. If the mode is unresolved, ask during/after and end the response; wait for the answer before any UI review, planning, or concept.
